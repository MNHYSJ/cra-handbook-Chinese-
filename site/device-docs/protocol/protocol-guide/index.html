    临床试验方案（Protocol）编写指南¶

    本指南用于规范医疗器械临床试验方案的撰写结构与内容要求，确保方案符合 GCP、ISO 14155 及监管部门的技术要求。方案质量直接决定中心执行的标准化程度、数据完整性与受试者安全保障水平。

    以下内容结合公开资料与行业规范整理（参考链接：
    1. 医疗器械临床方案主要内容（附模板）：https://www.cirs-group.com/cn/md/lin-chuang-ke-pu-yi-liao-qi-xie-lin-chuang-shi-yan-fang-an-zhu-yao-nei-rong-fu-lin-chuang-shi-yan-fang-an-mo-ban
    2. 医疗器械临床试验方案模板说明（知乎）：https://zhuanlan.zhihu.com/p/705091892 ）。

    1. 编写原则概述¶

    1. 内容必须明确、可操作、可检验，避免模糊措辞。
    2. 所有章节必须与受试者保护、安全性管理和数据质量密切相关。
    3. 方案内容必须与 ICF、CRF、监查计划保持一致，不得出现矛盾。
    4. 所有流程与定义应当事先设定，减少试验中途的解释空间。
    5. 对医疗器械试验而言，应重点体现设备相关风险、使用路径和操作标准。

    2. 方案结构编写要点¶

    2.1 封面与标题¶

    应包含产品名称、试验名称、版本号、日期、申办方、PI 信息。
    注意版本控制，应保持唯一版本号与发布日期对应。

    2.2 修订记录¶

    需记录每次修订的内容、原因、修订者。方案是一份受控文件，应保持记录链路清晰。

    2.3 背景与立项依据¶

    需要包括：
    1. 产品原理、构造、预期用途及市场背景。
    2. 前期资料（性能测试、动物实验、同类产品）的总结。
    3. 风险–收益评估，尤其是器械的操作风险、误用风险。
    4. 明确提出试验目的与终点设定的依据。

    写作技巧：所有背景引用务必来源明确，可使用公开资料、文献或技术文档。

    2.4 试验设计¶

    应包含：
    1. 研究类型（前瞻性、随机、非随机）、对照方式、盲法设置。
    2. 中心数量、样本量及其依据。
    3. 访问计划、数据采集节点。
    4. 偏倚控制方法，包括培训、校准、数据核查方式。

    医疗器械特别注意：
    需详细描述设备安装、操作、校准、维护路径（参考：https://zhuanlan.zhihu.com/p/705091892）。

    2.5 入排标准¶

    要求：
    1. 纳入标准应反映目标人群，易判断、可操作；
    2. 排除标准必须对应风险控制逻辑，例如安全性顾虑或设备禁忌症；
    3. 所有标准需保持原始医学术语，避免模糊描述。

    2.6 终点指标¶

    主要终点必须符合：可测量、可重复、数据来源明确。
    特别是器械试验，应确保终点能反映产品性能（例如手术成功率、操作稳定性、影像测量指标等）。

    2.7 访视安排与程序¶

    应设计访问表格（Visit Schedule），定义每个时间点的活动、检测项目、AE 监测等。
    确保 CRF 与访视表一致（不一致是常见稽查问题）。

    2.8 安全性管理¶

    包括：
    1. AE/SAE 定义、判定、上报时间
    2. ADE（器械不良器械事件）与 SADE 定义
    3. 设备异常、报警、故障须单独设定记录方式
    4. 风险缓解措施与应对流程

    医疗器械常见要求来自于 ISO 14155，建议在方案中引用并保持一致。

    2.9 统计学部分¶

    需要明确：
    1. 样本量估算原理
    2. 统计方法、显著性水平、缺失值处理方法
    3. 安全性分析人群、有效性分析人群的定义（如 ITT、PP、SAF）

    2.10 伦理与注册¶

    应明确：
    1. 知情同意流程
    2. 伦理委员会审批要求
    3. 注册平台（ChiCTR 或 ClinicalTrials.gov）的基本义务
    4. 隐私保护措施和数据保护机制

    2.11 文件管理与质量控制¶

    包括：
    1. 稽查准备；
    2. 文件归档路径（TMF/ISF）；
    3. 偏差记录和 CAPA 标准处理方式。

    2.12 附件¶

    访问计划表格、CRF 样稿、设备安装说明、培训材料等。

    3. 方案质量常见问题与避免策略¶

    1. 入排标准互相矛盾。
    2. 方案终点描述含糊、不具备测量可行性。
    3. 操作流程未细化，研究中心执行无法统一。
    4. ICF 与 Protocol 信息不一致（尤其风险部分）。
    5. 对设备相关风险描述不足。
    6. 数据处理策略缺失或逻辑不完整。
    7. 与监管要求不一致，未按照 ISO 14155 格式撰写。

    4. 编写流程建议¶

    1. 编写初稿前整理所有基础资料（设备技术资料、临床前数据、风险分析）。
    2. 按模板填写所有章节。
    3. 内部医学、质量、统计部门初审。
    4. 修订后进行跨部门 Review。
    5. 进行版本控制，形成最终版本。
