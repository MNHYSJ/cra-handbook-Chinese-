    Query 处理指南（Query Handling）¶

    Query 是数据管理（Data Management）过程中用于核查数据一致性、有效性、逻辑性的重要工具。及时、准确地处理 Query 是保证数据质量、减少偏差和促进数据库冻结的关键步骤。

    本指南概述 Query 的类型、形成原因、处理流程及质量要求，适用于药物与医疗器械临床试验。

    1. Query 的定义¶

    Query 指数据管理人员、统计人员、CRA 或系统自动生成的用于提示数据异常、不完整或逻辑不一致的询问信息。其目的在于让研究中心对数据进行核实、补充或更正。

    2. Query 的主要类型¶

    2.1 自动逻辑 Query（System-Generated Query）¶

    1. 由 EDC 系统的逻辑规则触发。
    2. 常见场景：

    4. 日期矛盾（如访视日期早于基线日期）
    5. 必填字段为空
    6. 不符合访视窗口

    2.2 手动 Query（Manual Query）¶

    由数据管理人员或 CRA 提出，常见原因包括：
    1. 病历与 EDC 数据不一致（SDV 检查结果）。
    2. AE/SAE 信息缺失或逻辑不完整。
    3. 设备使用或操作记录不一致（仪器试验特有问题）。
    4. 实验室数据未填写单位或标记“异常”却无解释。
    5. 访视未完成但无备注。

    2.3 医学 Query（Medical Query）¶

    由医学监查团队提出，用于核查：
    1. SAE 的医学判断是否合理。
    2. 药物合用、并用药记录是否完整。
    3. 器械临床事件是否准确分类（ADE/SADE）。
    4. 不良事件是否与产品相关。

    3. Query 处理流程¶

    3.1 研究中心收到 Query¶

    1. CRC 登录 EDC 查看 Query 列表。
    2. 按类别进行初步分类（医疗判断类需 PI 处理）。

    3.2 查阅原始资料（Source Document）¶

    中心应参照以下资料核实数据：
    1. 病历记录
    2. 检查结果（影像、实验室报告等）
    3. 器械使用日志（医疗器械试验）
    4. AE/SAE 报告表
    5. ICF、入排标准文件

    3.3 完成数据更新或解释¶

    处理方式包括：
    1. 更正错误数据（如录入错误）。
    2. 补充缺失信息。
    3. 提供医学解释（需 PI 签字）。
    4. 如遇无法确定的情况，可提出“需复核”备注。

    3.4 提交并关闭 Query¶

    1. CRC 提交处理后的内容。
    2. 数据管理人员复核并关闭 Query。
    3. CRA 在监查中进行后续核查。

    4. Query 处理时限要求¶

    各项目可能不同，但常见要求：
    - 普通 Query：3–5 个工作日
    - SAE 相关 Query：24–48 小时
    - 数据锁定前 Query：需全部完成关闭
    - PMCF 或器械试验可能要求更快响应

    未按时处理 Query 会延误：
    1. 中心数据质量评估
    2. 数据库冻结
    3. 统计分析启动
    4. 最终 CSR（Clinical Study Report）撰写

    5. Query 质量要求¶

    5.1 准确性¶

    1. 数据更正必须与原始记录一致。
    2. 不允许“猜测性填补”或随意赋值。

    5.2 完整性¶

    1. 所有 Query 均需处理，不得遗漏。
    2. 医学相关 Query 必须由 PI 确认。

    5.3 可追溯性¶

    1. 病历核查信息需在原始资料上体现（如签字或备注）。
    2. 修改记录应留痕。

    5.4 规范性¶

    1. 不得使用模糊描述：“已核实”、“无异常”等。
    2. 必须说明具体核查依据。

    6. 常见 Query 及处理方式举例¶

    6.1 数值异常¶

    示例： 血压录为 20/10 mmHg
    处理：
    - 查阅原始资料 → 更正 → 提供说明（如录入错误）。

    6.2 日期不一致¶

    示例： AE 发生日期晚于受试者退出日期
    处理：
    - 查阅病历 → 确定真实日期 → 修正数据。

    6.3 AE 未标注是否结束¶

    处理：
    - 查阅原始记录 → 补充结束日期或说明“未结束”。

    6.4 医疗器械 ADE 信息不完整（器械试验特有）¶

    处理：
    - 提供设备序列号、使用模式、报警信息、是否影响受试者。

    7. Query 管理建议¶

    7.1 对中心¶

    1. 每周至少一次检查 EDC Query 列表。
    2. 建立 Query 清单（Excel 或系统自动）。
    3. 将医学 Query 单独标记，需由 PI 处理。

    7.2 对 CRA¶

    1. 在 IMV 前生成 Query 报表并通知中心。
    2. 核查中心 Query 处理的准确性。
    3. 提醒中心数据库锁定时间节点。

    7.3 对申办方/CRO¶

    1. 设置重要 Query 的升级路径。
    2. 对重复出现的错误项提供专项培训。
