    稽查准备指南（Audit Preparation）¶

    稽查（Audit）是申办方或第三方为评估临床试验是否遵循 GCP、ISO 14155、方案与 SOP 等要求而实施的系统性审查。充分的稽查准备可显著降低重大不符合项风险，并确保中心与申办方均能通过监管检查。

    1. 稽查类型¶

    1.1 申办方稽查（Sponsor Audit）¶

    由申办方内部质量部门执行，目的是确保 CRO、中心执行与数据质量符合要求。

    1.2 CRO 稽查¶

    CRO 内部对各中心和项目团队进行质量评估。

    1.3 第三方稽查¶

    例如上市前准备、合作方审计等。

    1.4 监管机构检查（Inspection）¶

    与稽查不同，为国家药监部门（如 NMPA、FDA、EMA）直接检查，属于高强度形式。

    2. 稽查前准备（Pre-Audit Preparation）¶

    2.1 文件准备（ISF/TMF）¶

    确认以下文件版本一致且齐全： 1. 方案及所有修订
    2. 最新 ICF 版本与伦理批件
    3. 委托书与 Delegation Log
    4. 培训记录（SIV、IMV、Protocol Training）
    5. 监查报告及中心回复
    6. IP/Device 入库、温控、使用与回收记录
    7. AE/SAE/ADE/SADE 文件
    8. 偏差（Deviation）及 CAPA 文件
    9. 受试者日志（筛查、入组、退出）
    10. 影像、实验室报告、原始资料等

    重点提醒：所有历史版本需保留，文件必须受控。

    2.2 数据准备¶

    1. EDC 数据录入无延迟。
    2. 无未处理 Query。
    3. 所有核查字段（如主要终点）已完成 SDV。
    4. 不一致项、缺失项已全部解决。

    2.3 现场准备¶

    1. PI/CRC 可参加访谈并熟悉项目情况。
    2. 药房准备 IMP/Device 库存、温控记录。
    3. 影像科或设备室需准备相关记录（器械试验）。
    4. 简化受试者现场调取流程，避免等待。

    3. 稽查当天流程（During Audit）¶

    3.1 开场会议（Opening Meeting）¶

    参与人员通常包括：
    - 稽查员
    - 申办方质量团队
    - PI
    - CRC
    - 药师、实验室负责人（如涉及）

    会议内容：
    1. 稽查目的与范围
    2. 稽查时间表
    3. 需要访问的资料与人员

    3.2 文件核查¶

    审查以下内容：
    1. ISF 结构是否完整
    2. 伦理批件是否对人、对中心
    3. ICF 是否符合批准版本
    4. 监查记录与回复是否及时
    5. 偏差记录是否规范

    3.3 原始资料核查（SDR/SDV）¶

    稽查员重点关注：
    1. 入排标准是否符合病历
    2. 访视流程执行是否符合方案
    3. AE/SAE 是否及时记录
    4. 设备或 IMP 使用记录是否一致
    5. 数据与原始资料的一致性

    3.4 药物/器械管理审查¶

    包括：
    1. 入库记录
    2. 温控监测（药物）或设备日志（器械）
    3. 发放与回收链路

    3.5 人员访谈¶

    稽查员可能分别访谈：
    - PI：入排判断依据、SAE 医学解释
    - CRC：数据录入、ICF 流程、访视执行
    - 药师：IMP 存储与发放
    - 实验室/影像科：数据来源流程

    4. 稽查后工作（Post-Audit）¶

    1. 稽查员形成稽查报告，列出发现（Finding）。
    2. 按严重程度分类：
    3. 重大（Major）
    4. 一般（Minor）
    5. 建议（Observation）
    6. 中心需在规定时间内提交纠正预防措施（CAPA）。
    7. CRA 应跟踪 CAPA 执行与文件补充。
    8. 所有稽查文件需归档至 TMF 和 ISF。

    5. 常见稽查问题（典型 Finding）¶

    5.1 ICF 流程违规¶

    1. ICF 使用错误版本
    2. 日期先后顺序不合理
    3. 缺少见证人签名（如需要）

    5.2 AE/SAE 管理不当¶

    1. 漏报或迟报
    2. 与病历记录不一致
    3. 因果关系未由 PI 认定

    5.3 文件管理缺陷¶

    1. ISF 文件缺失
    2. 版本控制不一致
    3. 旧版本未归档

    5.4 数据问题¶

    1. 数据缺失
    2. EDC 与原始资料不一致
    3. 主要终点数据不完整

    5.5 设备/IMP 管理不合规¶

    1. 温控记录缺失
    2. 设备使用日志不完整
    3. 库存不一致

    6. 稽查风险降低策略¶

    6.1 对研究中心¶

    1. 建立稽查资料夹（按模块摆放）。
    2. 定期自检 ISF 和记录表。
    3. 在 IMV 中解决所有潜在风险。

    6.2 对 CRA¶

    1. 访视时使用标准检查清单。
    2. 提前进行预稽查（Mock Audit）。
    3. 提供偏差登记与 CAPA 模板。

    6.3 对申办方/CRO¶

    1. 建立质量管理计划（QMP）。
    2. 加强监查力度与频率。
    3. 将常见问题纳入培训内容。

    7. 总结¶

    稽查是验证试验质量、发现风险与确保合规的重要过程。充分准备、规范记录和及时整改是通过稽查的关键。稽查不仅是检查，也是一种质量改进机制，通过稽查能够持续提升中心与申办方的临床试验执行能力。
