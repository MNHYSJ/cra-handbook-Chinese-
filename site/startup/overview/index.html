    项目启动总览与时间线¶

    1. 项目启动的定义¶

    项目启动（Study Start-up）是临床试验正式开展前的准备阶段，涉及法规、伦理、中心筛选、合同预算、试验产品准备、文件管理、系统搭建及多方协调。启动阶段的合规性与完整性直接影响后续入组效率、数据质量和中心合规性。

    2. 项目启动的核心目标¶

    1. 确保所有程序满足 GCP、ISO 14155 及相关监管要求。
    2. 确保所有研究中心在启动前完成必要的行政、伦理、合同及培训准备。
    3. 确保方案、SOP 及各类试验文件均可操作、可执行。
    4. 确保受试者招募路径、设备安装、人员培训均已妥善落实。

    3. 项目启动阶段的主要工作内容¶

    3.1 试验前准备（Pre-start-up）¶

    1. 制定研究总体时间线与内部责任分工。
    2. 完成核心文件定稿（Protocol、IB/IFU、ICF 初版、Synopsis 等）。
    3. 完成风险评估（Risk Assessment）与监查计划（Monitoring Plan）。
    4. 确定数据库结构与 CRF 雏形设计。
    5. 确认申办方对中心数量、入组节奏和预算的要求。

    3.2 站点筛选与确定（Site Selection）¶

    1. 初步中心筛查：患者量、资源、合规性及以往试验经验。
    2. 安排预考察访视（PSV）评估中心执行能力。
    3. 形成最终站点名单并提交申办方批准。

    3.3 行政与合同管理¶

    1. 中心合同与研究者合同的谈判及签署。
    2. 预算核算、付款节点确认及结算方式确定。
    3. 中心伦理相关费用及行政费用确认。

    3.4 伦理与监管审批¶

    1. 提交伦理材料（Protocol、ICF、IB、CRF 样稿、广告等）。
    2. 跟踪伦理委员会（EC/IRB）批准状态。
    3. 若为医疗器械，还需进行必要的试验注册（如 ChiCTR）。
    4. 管理修订文件及后续再提交。

    3.5 系统与试验材料准备¶

    1. 数据系统（EDC/IRT）开发、UAT 验证与用户账户分配。
    2. 试验产品（IMP/Device）准备、追踪标签、物流计划。
    3. 中心 ISF 初始化文件准备。
    4. 受试者招募材料与广告内容的批准与发放。

    3.6 研究者会议（IM）与 SIV 准备¶

    1. 完成中心团队培训（Protocol、GCP、设备使用等）。
    2. 准备 SIV 清单及现场启动准备。
    3. 确认受试者招募流程、样本管理流程及访视路径。

    4. 项目启动的标准时间线（参考）¶

    4.1 典型时间线（按执行顺序）¶

    1. 初步立项与内部评估：1–3 周
    2. 中心初筛及 PSV：2–6 周
    3. 伦理资料定稿与提交流程：2–8 周
    4. 合同与预算谈判：4–12 周（通常为最耗时环节）
    5. 系统搭建与 UAT：2–6 周
    6. 试验产品与物流准备：2–4 周
    7. SIV 计划与执行：2–4 周
    8. 首例入组（FPI）：项目启动的最终标志

    4.2 影响时间线的关键因素¶

    1. 中心合同处理速度（差异大）。
    2. 伦理审查周期与是否需要多中心联审。
    3. 系统开发复杂程度（尤其医疗器械伴随设备的数据结构）。
    4. 产品供应链及标签准备。
    5. 中心团队对项目优先级的投入程度。

    5. CRA 在项目启动阶段的职责重点¶

    1. 参与中心筛选、完成 PSV 报告。
    2. 完成 ISF 文件准备与分发。
    3. 协助中心伦理提交材料的准备。
    4. 跟踪系统培训、GCP 与项目培训的完成情况。
    5. 与 CRC/PI 确认受试者招募路径是否可行。
    6. 完成 SIV 并确认中心具备入组条件。
    7. 记录启动阶段的所有偏差、文件修订与未解决问题。
