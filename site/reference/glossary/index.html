    中英缩写表（Clinical / Medical Device / BCI）¶

    缩写 英文全称 中文含义
    BCI / BMI Brain–Computer Interface / Brain–Machine Interface 脑机接口
    iBCI Implantable BCI 植入式脑机接口
    eBCI External BCI 体外脑机接口
    LFP Local Field Potential 局部场电位
    ERP Event Related Potential 事件相关电位
    FES Functional Electrical Stimulation 功能性电刺激
    NHP Non-human Primate 非人灵长类动物
    Decoder Neural Decoder 神经解码器

    6.2 侵入式电极类别¶

    缩写 英文全称 中文含义

    Depth Electrode N/A 深部电极（进入脑组织）
    DBS Deep Brain Stimulation 深部脑刺激（如 STN、GPi）

    μECoG Micro-ECoG 微型皮层电极
    Grid/Strip Grid / Strip Electrodes 网格/条状电极（ECoG 专用）
    Cortical Implant N/A 皮层植入体
    Penetrating Electrode N/A 穿透型电极
