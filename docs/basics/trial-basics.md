# 临床试验基本概念

## 1. 临床试验定义
临床试验是为评估药物、医疗器械或其他干预措施的安全性、有效性及临床性能而在人体受试者中开展的系统性研究。研究需遵从试验方案、伦理原则（如《赫尔辛基宣言》）、GCP/ISO 14155 及相关法规。

## 2. 医疗器械与药物临床试验的差异要点

### 2.1 监管体系
1. 药物侧重药效学、药代动力学、安全性及有效性。  
2. 医疗器械侧重临床性能、临床收益与风险—收益比评估（ISO 14155）。  
3. 器械临床强调设备安装、使用培训、追踪性（UDI）等要求。

### 2.2 风险分级
1. 药物按照化学性质及作用机制监管。  
2. 医疗器械按照风险等级（I/II/III）管理，风险越高，临床证据要求越严格。

### 2.3 受试者风险关注点
1. 器械相关风险包括操作风险、材料相容性、电磁安全等。  
2. 药物主要关注给药安全、药代动力学及系统性反应。

## 3. 临床试验常见阶段（药物为例）
1. I 期：初步安全性、耐受性、药代动力学评估。  
2. II 期：探索性疗效、安全性和剂量。  
3. III 期：确证有效性、安全性及风险—收益比。  
4. IV 期：上市后真实世界数据收集、长期安全性监测。

医疗器械通常不完全按 I–IV 期划分，而是按以下流程：
1. 临床前性能与安全性验证  
2. 临床试验必要性评估  
3. 临床性能试验（根据 ISO 14155）  
4. 上市后临床随访（PMCF）

## 4. 临床试验的关键组成要素

### 4.1 试验方案（Protocol）
1. 研究目的与终点明确、可测量、可操作化。  
2. 明确入排标准、流程、访问计划及统计方案。  
3. 包含受试者安全性监测及不良事件处理策略。

### 4.2 伦理保障
1. 知情同意过程必须充分、真实、自愿。  
2. 受试者隐私保护与数据安全管理。  
3. 不得排除受试者合理治疗的机会。

### 4.3 质量管理
1. 监查（Monitoring）确保试验按方案执行。  
2. 稽查（Audit）评估系统性质量。  
3. 检查（Inspection）由监管机构开展。

### 4.4 数据管理
1. EDC 系统构建与 CRF 设计。  
2. 数据清理与 Query 处理。  
3. 数据冻结与统计分析。

## 5. 临床试验的核心目标
1. 保护受试者权益与安全。  
2. 生成科学、可靠、可重复的临床证据。  
3. 最终支持注册申报或产品改良的临床依据。
