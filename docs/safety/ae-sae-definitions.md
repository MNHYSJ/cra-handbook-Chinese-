# AE 与 SAE 定义速查

## 1. 不良事件（Adverse Event, AE）的定义
不良事件是指在受试者接受试验相关程序后出现的、任何不利的医学事件。该事件可以是任何不良的临床症状、检查异常或疾病的发生或恶化，无论其是否与试验产品具有因果关系。

AE 的范围包括：
1. 临床症状变化（如头痛、恶心、疲劳）。  
2. 实验室检查异常（如肝酶升高）。  
3. 影像学或心电图异常。  
4. 既往疾病的恶化或新发疾病。  
5. 针对医疗器械试验，可包含设备相关操作中的不良反应或设备使用过程中出现的异常体验。

AE 的定义强调广泛性，不要求事件与试验产品之间存在因果关系。

## 2. 严重不良事件（Serious Adverse Event, SAE）
SAE 指导致以下任一后果的事件：

1. 导致死亡。  
2. 危及生命（Life-threatening）。  
3. 需要住院治疗或延长既往住院时间。  
4. 导致持久或显著的残疾或功能障碍。  
5. 导致先天畸形或出生缺陷。  
6. 医学上具有重要意义的事件，即使不符合上述标准，研究者认为其可能危及受试者或需要采取医学干预以避免上述严重后果。

ISO 14155 在医疗器械领域的 SAE 扩展说明：
- 与器械操作相关的事件，如设备使用过程中的火花、电击、热损伤等，若具有潜在重大风险，也可归类为 SAE。  
- 若设备停止工作、功能异常或出现错误信息导致受试者风险增加，也应纳入 SAE 的评估范围。

## 3. 不良器械事件（Adverse Device Effect, ADE）
适用于医疗器械试验，特指与器械使用可能相关的不良事件。

ADE 的特点：
1. 事件与器械的功能、操作、材料或使用过程可能存在关联。  
2. 包括机械故障、人机界面错误、能量输出异常、软件错误等导致的事件或风险增加。  
3. 若 ADE 同时符合 SAE 标准，则为 SADE（Serious Adverse Device Effect）。

## 4. 与因果关系相关的术语

### 4.1 与试验产品无关（Not related）
事件明显由其他因素导致，与产品或试验程序不存在关联性。

### 4.2 可能相关（Possibly related）
无法排除产品或试验程序与事件发生之间的联系。

### 4.3 很可能相关（Probably related）
证据显示事件具有较强的时间关系及生物学合理性。

### 4.4 明显相关（Definitely related）
事件在产品使用后出现，且停止使用后症状显著改善，排除其他可解释的原因。
