# 常规监查访视（Interim Monitoring Visit, IMV）

常规监查访视是确保临床试验按方案一致、受试者安全得到保障、数据完整准确的重要途径。CRA 在 IMV 中的任务包括数据核查、流程监督、文件管理检查以及风险识别。

---

## 1. IMV 的目标
1. 确保中心遵循方案、伦理、GCP/ISO 14155。  
2. 核查所有受试者数据的准确性、完整性和一致性。  
3. 确保 AE/SAE/ADE 记录与原始病历一致。  
4. 核查 IMP/Device 的使用、存储、日志记录。  
5. 发现并纠正偏差、风险点。  

---

## 2. IMV 前准备（Pre-IMV）
1. EDC 数据预审并准备 Query 清单。  
2. 整理受试者列表（筛查、入组、完成、退出）。  
3. 准备重点核查项目，如：  
   - 最新伦理批件  
   - AE/SAE 未关闭记录  
   - 产品库存  
4. 向中心发送访视通知（含需准备的材料）。  

---

## 3. IMV 流程（During IMV）

### 3.1 与研究团队沟通
1. 与 PI 讨论医学相关事项（退组、SAE、入排判断）。  
2. 与 CRC 了解执行情况、遇到的问题和数据进度。  

### 3.2 受试者管理核查
1. 入排标准核查（SDR）。  
2. 知情同意文件核查（ICF 版本、签名日期、流程完整性）。  
3. 访视计划执行情况（窗口、漏项、错项）。  

### 3.3 数据核查（SDV/SDR）
根据监查计划进行：
1. SDV（Source Data Verification）：核对病历与 EDC 一致性。  
2. SDR（Source Data Review）：评估流程、记录完整性。  
3. 重点项目：生命体征、实验室数据、主要终点相关数据。  

### 3.4 不良事件管理核查
1. 核查 AE/SAE 是否完整记录。  
2. AE 是否及时录入 EDC。  
3. SAE 是否在时限内上报并完成医学判断。  
4. 若为器械试验：检查报警、设备异常记录。

### 3.5 IMP/Device 管理核查
1. 入库记录、库存数量、温控记录。  
2. 使用记录是否与受试者编号一致。  
3. 器械试验需核查设备日志、维护记录、故障处理。  

### 3.6 ISF 文件核查
确认以下文件是否最新：  
1. 伦理批件、培训记录、委托书  
2. 方案与 ICF 的最新版本  
3. 监查报告与回复记录  
4. 偏差报告与 CAPA 文件  

---

## 4. IMV 后工作（Post-IMV）
1. 完成监查报告，提交申办方审核。  
2. 向中心发送访视总结（Summary Mail）。  
3. 跟踪未关闭项：  
   - Query  
   - 文件补充  
   - 偏差整改  
4. 必要时进行远程监查补充。

---

## 5. IMV 风险识别重点
1. 数据录入延迟。  
2. ICF 签署流程错误（最常见稽查问题）。  
3. AE 漏报或迟报。  
4. 设备日志缺失（器械试验特有问题）。  
5. 偏差未及时记录。  
6. Delegation Log 与实际情况不符。
