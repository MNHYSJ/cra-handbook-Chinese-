# 选点（Site Selection）

**标签**：#立项 #启动 #选点 #检查清单

## 1. 目标

- 评估中心患者量、团队经验、设备条件，判断是否适合开展研究。
- 确保后续入组和随访可行，减少项目中途卡壳的风险。

## 2. 访视前准备

- 从申办方获取：方案概要、入排标准、预期入组数。
- 收集中心基础信息：床位、门急诊量、相关科室情况。
- 确认研究团队成员：PI、Sub-I、CRC、药师、实验室负责人等。

## 3. 现场检查清单

- 患者资源：过去一年相关疾病门诊/住院量、竞争试验情况。
- 研究团队：GCP证书、有无以往试验经验、人员时间是否充足。
- 设施设备：药房条件、温度监测、实验室检测能力和报告时效。
- 合规性：伦理委员会情况、以往是否有稽查/检查问题记录。

## 4. 常见问题 & 小技巧

- 中心容易夸大患者量 → 尽量要求提供客观统计数据。
- 团队资源不足 → 及早评估，必要时向申办方反馈调整入组预期。
