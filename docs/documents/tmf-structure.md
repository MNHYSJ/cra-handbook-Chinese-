# TMF 与 ISF 文件结构指南

Trial Master File（TMF）与 Investigator Site File（ISF）是保证临床试验合规性、可追溯性与可稽查性的核心文件集合。TMF 属于申办方（或 CRO 代表申办方），ISF 属于研究中心。两者需保持文件内容的一致性，但承担不同记录责任。

本文件提供医疗器械及药物临床试验通用的 TMF/ISF 文件结构框架。

---

## 1. TMF 与 ISF 的主要差异

### 1.1 TMF（Trial Master File）
由申办方或 CRO 管理，包含试验全生命周期的所有试验文件，覆盖：
- 启动阶段文件  
- 试验执行过程文件  
- 数据与安全性记录  
- 稽查与监管检查记录  
- 关闭文件  

TMF 可采用电子形式（eTMF），须具备版本控制、权限管理、审计追踪等功能。

### 1.2 ISF（Investigator Site File）
由研究中心保存，文件内容聚焦于中心实际执行层面，包含：
- 中心版伦理文件  
- 中心人员资质、Delegation Log  
- 受试者访视相关的原始记录  
- 药物/器械管理记录  
- 监查记录与整改记录  

ISF 的文件量少于 TMF，但必须保持完整性与最新版本。

## 2. TMF 文件结构（申办方/CRO）

以下为推荐结构，以模块方式呈现：

### 2.1 项目管理（Project Management）
1. 项目计划书（Project Plan）  
2. 会议纪要与沟通记录  
3. 职责分工（Sponsor/CRO/第三方）

### 2.2 方案与相关文件（Protocol & Amendments）
1. 方案（Protocol，含版本历史）  
2. 修订文件（Amendment）  
3. ICF 及其修订版本  
4. 试验手册（IB/IFU）  
5. CRF 及 EDC 设计文件

### 2.3 法规与伦理（Regulatory & Ethics）
1. 伦理批件（各中心）  
2. 监管机构沟通记录  
3. 注册文件（ChiCTR/ClinicalTrials.gov）  
4. 保险文件

### 2.4 监查与质量管理（Monitoring & QA）
1. 监查计划（Monitoring Plan）  
2. 监查报告及总结  
3. 稽查报告  
4. 风险管理文件（包括设备风险分析 ISO 14971）

### 2.5 安全性记录（Safety）
1. AE/SAE 报告  
2. 医学判断记录  
3. 向监管部门的安全报告  
4. 设备事件报告（ADE/SADE）

### 2.6 数据管理（Data Management）
1. 数据管理计划（DMP）  
2. Query 清单与处理记录  
3. 数据库冻结记录  
4. 数据传输协议

### 2.7 药物/器械管理（IP/Device Management）
1. 试验产品物流、配送、回收记录  
2. 温控或设备功能验证记录  
3. 设备使用日志（如属于申办方责任）

### 2.8 关闭文件（Close-out Documentation）
1. 关闭访视报告  
2. 中心关闭确认函  
3. 文件归档记录  
4. 数据锁定记录

---

## 3. ISF 文件结构（研究中心）

### 3.1 方案与核心文件
1. 当前版本的方案（Protocol）  
2. 方案修订与替换记录  
3. ICF 所有当前和历史版本  
4. IB/IFU  
5. CRF 样稿

### 3.2 伦理与监管
1. 本中心伦理批件（初次与修订）  
2. 中心提交伦理的材料/回执  
3. 中心获批的招募材料  
4. 注册信息（若要求中心提供）

### 3.3 中心人员与资质
1. PI 简历、GCP 证书  
2. 研究团队 CV 和 GCP 证书  
3. Delegation Log  
4. 培训记录（SIV/IMV/COV）

### 3.4 受试者相关文件
1. 筛查日志  
2. 入组日志  
3. SAE/ADE 记录  
4. 退出/停用文档通知  
5. 随访记录（如适用）

### 3.5 监查与沟通
1. CRA 监查访视报告及中心回复  
2. 监查通知  
3. 项目会议纪要

### 3.6 IMP/Device 管理
1. 入库记录  
2. 存储温控记录（药物）  
3. 发放与回收记录  
4. 器械使用日志、报警日志  
5. 设备安装/校准记录（医疗器械试验特有）

### 3.7 文件归档与关闭
1. COV 记录  
2. 关闭确认通知  
3. 文件保留年限说明

---

## 4. 文件管理要求（TMF/ISF 通用）

### 4.1 版本控制
1. 所有文件需标注版本号、发布日期。  
2. 历史版本须保留但标记“过期”。  
3. 禁止出现无版本号的文件。

### 4.2 稽查追溯性
所有文件必须可追溯，包括：
- 创建者  
- 审核者  
- 修改历史  
- 使用期间的记录  

### 4.3 文件一致性要求
1. ISF 与 TMF 中同名文件应版本一致。  
2. 中心版 ICF 必须与伦理批件匹配（常见稽查问题）。  

---

## 5. 归档要求
1. 分中心文件归档于 ISF，申办方文件归档于 TMF。  
2. 需按照法规保持至少 5 年或根据当地法规更长年限。  
3. 医疗器械试验可能因上市后随访（PMCF）延长保存期限。
