# 医疗器械临床 CRA 个人自查手册

> 这是我基于个人兴趣整理的一个 **自查小网站**，  
> 用来记录和复习医疗器械临床试验工作中的各个步骤和文档编写要点。  
> **只代表个人理解，不构成任何官方或法律建议。**

---

## 这个网站是用来干嘛的？

- 帮自己快速回顾：**项目启动 / 伦理 & 注册 / 监查访视 / 安全事件** 等流程。
- 自查常见文档：**SOP、临床试验方案（Protocol）、CRF 设计** 的结构和注意事项。
- 记录一些踩坑经验，方便以后换项目或换公司时赶快捡回记忆。

---

## 使用方式

- 遇到新项目 / 新 SOP：  
  → 把重点结构和注意事项整理到对应页面。
- 做方案 / CRF 时：  
  → 先打开这里看一眼之前的 checklist，避免漏项。
- 每次踩坑：  
  → 记到「个人经验 & 小技巧」模块里，提醒自己下次别再踩。
