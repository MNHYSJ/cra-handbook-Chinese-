    结束访视（Close-out Visit, COV）¶

    结束访视的目标是确认研究中心已完成所有试验相关活动、数据整理、文件归档和试验产品回收，并确保中心为稽查或检查做好准备。

    1. COV 的目的¶

    1. 确保所有数据已录入并完成 Query 关闭。
    2. 确认所有受试者完成访视或已处理退出流程。
    3. ISF 文件完整且已准备归档。
    4. 试验产品与设备已回收或报废。
    5. 协助中心准备接受稽查或监管检查。

    2. COV 前准备¶

    1. 确认 EDC 数据清零：
    2. 无未处理 Query
    3. 无逻辑错误
    4. 所有 AE/SAE 已处理结束
    5. 确认中心不再有受试者在访。
    6. 准备 COV 核查清单：
    7. ISF 文件检查清单
    8. 产品回收记录
    9. 设备移除计划
    10. 通知中心访视时间与准备事项。

    3. COV 流程（During COV）¶

    3.1 文件与数据关闭¶

    1. 查询所有受试者数据是否已完整录入。
    2. 确认主要终点数据、实验室数据、影像资料已归档。
    3. 核查受试者退出、停用、失访原因记录。

    3.2 ISF 最终核查¶

    需确认 ISF 包含完整文件，包括： 1. 最终版方案与 ICF。
    2. 所有伦理批件（含修订）。
    3. 培训记录（包括 SIV、IMV、COV 培训）。
    4. 监查报告与中心回复记录。
    5. AE/SAE 完整记录。
    6. 偏差及 CAPA 文件。

    3.3 试验产品与设备管理¶

    1. 试验产品库存核对与回收。
    2. 器械试验需核查：
    3. 设备拆卸、回收、封存记录
    4. 设备的最终维护与确认
    5. 使用日志完整性

    3.4 行政与合同事项¶

    1. 中心费用核对与支付流程启动。
    2. 最终受试者补偿统计。
    3. 中心保存文件的年限说明。

    3.5 中心风险提示与后续要求¶

    1. 若试验需要 PMCF（上市后临床随访），需告知中心要求。
    2. 监管部门可能要求的检查事项提示。

    4. COV 后工作（Post-COV）¶

    1. 提交 Close-out Report。
    2. 更新 TMF。
    3. 启动最终数据库锁定流程。
    4. 向中心发送试验结束通知和归档说明。

    5. COV 合格标准¶

    1. 所有数据已完成录入和核查。
    2. 所有 Query 已关闭。
    3. 所有 AE/SAE 已处理完毕。
    4. ISF 完整归档。
    5. 试验产品与设备已全部回收。
    6. 中心已正式完成试验所有任务。
