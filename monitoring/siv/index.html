    启动访视（Site Initiation Visit, SIV）¶

    启动访视的核心目标是确保研究中心在正式入组前具备完整的试验条件、文件、人员培训与资源配置。SIV 是确保试验按方案执行的关键节点。

    1. SIV 的目的与必要性¶

    1. 确认中心已获得伦理批准、合同到位、ISF 完整。
    2. 进行完整的方案培训和试验流程讲解。
    3. 确保中心已理解设备使用方法（如医疗器械试验）。
    4. 确保受试者招募、数据管理和AE/SAE处理流程均已建立。
    5. 评估中心是否满足入组条件。

    2. SIV 前准备（Pre-SIV Preparation）¶

    2.1 文件准备¶

    1. 伦理批件（正式批准、修订批准）。
    2. ISF 初始化文件包含：
    3. 方案（Protocol）
    4. ICF 版本
    5. IB/IFU
    6. CRF 样稿
    7. 招募材料
    8. 委托书、 Delegation Log 初版
    9. 监查计划、数据管理计划

    2.2 试验材料准备¶

    1. 设备配送与安装记录（器械试验）。
    2. 试验产品入库计划（IMP 或 Device）。
    3. EDC/IRT 系统账号准备。
    4. 样本采集包、耗材、表格等。

    2.3 CRA 内部准备¶

    1. 制作 SIV 培训 PPT 与讲义。
    2. 准备中心专属访视议程。
    3. 检查中心是否满足 SIV 前置条件，如：
    4. 合同签署完成
    5. 伦理批件到位
    6. 研究团队名单提交

    3. SIV 访视流程（During SIV）¶

    3.1 研究团队会议¶

    与 PI、CRC、药师、实验室负责人等进行培训与讨论。

    3.2 方案培训（Protocol Training）¶

    应详细讲解： 1. 试验目的、终点、关键概念与风险控制点。
    2. 入排标准（与病历筛查相关）。
    3. 访视流程与访问时间窗口。
    4. 数据采集节点与 CRF 填写规则。
    5. 安全事件（AE/SAE/ADE/SADE）定义与上报要求。

    3.3 数据系统培训¶

    1. EDC 登录、数据录入、Query 回复。
    2. IRT/Randomization 流程（如适用）。
    3. CRF 字段的逻辑检查。

    3.4 试验产品（IMP/Device）管理培训¶

    1. 入库、存储（温控要求）。
    2. 发放记录。
    3. 器械使用记录、维护记录。
    4. 产品回收与报损流程。

    3.5 ISF 逐项核对¶

    核查内容： 1. 文件是否齐全、版本是否一致。
    2. Delegation Log 是否已填写主要人员。
    3. 培训记录是否准备好签名归档。

    3.6 中心准备评估¶

    1. 设备（器械试验）是否完成安装和验证。
    2. 药房/器械库是否具备条件。
    3. CRC 是否了解访视流程和数据录入要求。
    4. PI 是否知晓医学判断职责。

    4. SIV 后工作（Post-SIV）¶

    1. 完成 SIV 报告并提交申办方。
    2. 整理中心未完成的准备项并跟踪关闭。
    3. 确认中心正式具备入组资格（Site Ready for Enrollment）。
    4. 向中心发送 SIV Summary 邮件。

    5. SIV 合格标准（Site Ready Checklist）¶

    1. 伦理批准到位。
    2. ISF 完整且已签名。
    3. 研究团队完成全部培训。
    4. 试验产品/设备已到位。
    5. EDC 账号已开通并登录测试通过。
    6. 中心具备招募第一例受试者的条件。
