    伦理提交材料清单¶

    1. 伦理审查的目的与原则¶

    伦理审查的目标是确保临床试验的设计与实施符合科学性与伦理性，保护受试者的权益、安全与隐私。伦理委员会（EC 或 IRB）依据《赫尔辛基宣言》、GCP、ISO 14155 及国内法规对试验进行独立审查。提交材料应完整、准确且版本受控。

    2. 伦理提交材料的核心组成¶

    2.1 试验方案（Protocol）¶

    1. 包含研究目的、设计、终点、统计方法及访问计划。
    2. 列明安全性管理、偏差处理及终止标准。
    3. 明确受试者权益保护、隐私管理与知情同意过程。

    2.2 知情同意书（Informed Consent Form, ICF）¶

    1. 内容需符合法规与伦理要求，语言清晰、易理解。
    2. 包含风险、收益、受试者权利、撤回机制及补偿信息。
    3. 如涉及生命体征采集、样本采集或图像采集，须明确说明范围及用途。
    4. 若为医疗器械试验，应说明设备使用方式及潜在操作风险。

    2.3 研究者手册（IB）或使用说明书（IFU）¶

    1. 药物试验提交 IB；医疗器械提交 IFU 或技术白皮书。
    2. 应详细描述产品性能、风险信息、临床前证据。
    3. 若存在器械安装、校准或培训要求，应在附件中说明。

    2.4 病例报告表样稿（CRF Sample）¶

    1. 反映受试者信息、访问计划、终点指标项及安全记录项。
    2. 确保 CRF 与方案终点一致。
    3. 若为 EDC，应提供截图或结构说明。

    2.5 受试者招募材料¶

    1. 包括招募海报、文案、医院外宣材料等。
    2. 内容需经伦理批准后方可使用。
    3. 不得包含夸大疗效内容或明确诱导性语言。

    2.6 研究团队的资质与文件¶

    1. 主要研究者（PI）简历及 GCP 培训证书。
    2. 研究团队成员名单、职责分工（Delegation Log）。
    3. 研究中心机构资质证明。

    2.7 程序性文件与质量保证材料¶

    1. 监查计划（Monitoring Plan）。
    2. 数据管理计划（DMP）。
    3. 安全管理计划（SAFETY Plan）。
    4. 医疗器械试验需提供风险管理文件（如 ISO 14971 风险分析摘要）。

    2.8 合同与预算（若伦理要求审查）¶

    1. 研究中心合同或经费预算表。
    2. 受试者补偿标准。
    3. 受试者交通补贴、误工补贴说明。

    2.9 法规或机构要求的特殊材料¶

    1. 保险凭证或受试者意外伤害保险方案。
    2. 医疗器械试验需要的设备说明、注册证或备案证明（如适用）。
    3. 多中心试验需提交各中心相关批件及联络信息。

    3. 伦理受理常见要求¶

    1. 所有文件需为最新版本，且有版本号、日期、页码。
    2. 所有提交文件需加盖机构公章或 PI 签名（视机构要求）。
    3. 文件内容需保持一致，如 Protocol 与 ICF 的风险信息不一致可能导致退回。
    4. 若试验涉及敏感数据（影像、样本），需明确数据流向及使用范围。

    4. 伦理退回的常见原因¶

    1. 方案目标或设计不清晰，安全管理措施不足。
    2. ICF 信息不完整或语言不清晰。
    3. 风险提示不足或未覆盖重要不良事件信息。
    4. 没有明确受试者撤回权利或数据处理流程。
    5. 招募材料内容不符合法规，不够客观。

    5. CRA 在伦理提交中的职责¶

    1. 协助研究中心整理提交材料，确保版本一致与格式规范。
    2. 跟踪伦理提交时间节点，及时向申办方汇报进度。
    3. 协助中心补充材料、修订文件或处理伦理退回意见。
    4. 保存伦理相关文件并及时更新 ISF 文件夹。
    5. 确保中心在获得伦理批准后方可开展试验相关活动。
